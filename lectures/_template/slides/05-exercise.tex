\begin{frame}{Вычислите ошибку предсказания}
  Известные цены: $4$, $6$, $8$ млн руб. Предсказания: $5$, $5$, $9$ млн руб.
  \begin{enumerate}
    \item Вычислите модуль ошибки для каждой квартиры.
    \item Найдите MAE и укажите единицы измерения.
    \item Найдите среднюю ошибку без модуля. Чем она отличается от MAE?
  \end{enumerate}
\end{frame}
