\begin{frame}{Разбор: ошибки разных знаков}
  Модули ошибок: $1$, $1$, $1$ млн руб.
  \[
    \mathrm{MAE}=\frac{1+1+1}{3}=1\text{ млн руб.}
  \]
  Ошибки со знаком: $1$, $-1$, $1$ млн руб.
  \[
    \frac{1-1+1}{3}=\frac13\text{ млн руб.}
  \]
  При усреднении ошибки разных знаков компенсируют друг друга.
  MAE учитывает величину каждого промаха.
\end{frame}
