# Примеры слайдов

Шесть слайдов разбирают один пример: данные, расчёт, код, упражнение и ответ. Это пример оформления, а не обязательный план занятия. Порядок задают `\input` в `main.tex`; при копировании замените содержание и метаданные.

Используйте обычный текст для объяснений, таблицу для сравнения, рисунок для зависимости. Блок нужен, если его заголовок помогает выделить определение или условие. Не добавляйте отдельный слайд ради формальной цели или итога.

Код размещайте в `frame[fragile]`, таблицы — в `tabularx` шириной `\linewidth` с колонками `Y` и линиями `booktabs`. В колонках используйте `columns[T,onlytextwidth]`. Если текст не помещается, сократите или разделите слайд; не уменьшайте весь текст.

Изображения храните в `assets/`; задавайте ширину и высоту с `keepaspectratio`. После изменений выполните `make tex DIR=lectures/_template` и просмотрите все страницы.

Общие команды: [LaTeX](../../../latex/README.md).
