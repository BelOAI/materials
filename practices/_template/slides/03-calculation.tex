\begin{frame}{Фильтр и среднее}
  Условию «площадь больше $40$ м$^2$» удовлетворяют квартиры B и C.
  \[
    \overline y=\frac{5+7}{2}=6\text{ млн руб.}
  \]
  Условие проверяется для каждой строки; среднее вычисляется по ценам выбранных квартир.
  \medskip\par
  Для пустой выборки среднее не определено. Если цены пропущены,
  pandas по умолчанию исключает их из расчёта.
\end{frame}
