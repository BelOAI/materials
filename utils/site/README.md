# Интерфейс сайта

Python генерирует главную, страницы недель и каталог из `course/course.json` и метаданных материалов. `index.html` — общий HTML-шаблон, `src/site.css` — оформление по компоновке CS50: серебристая колонка 320 px, логотип Unbounded, основной текст PT Sans и вложенные списки ресурсов. До 992 px навигация переносится в верхний блок с раскрываемым меню. PT Sans поставляется локально в обычном и жирном начертании вместе с OFL.

`src/materials-app.js` регистрирует компоненты Lit. `materials-catalog` загружает манифест и фильтрует только вложенный статический список; `catalog-controls` получает состояние через свойства и отправляет события `query-change` с `detail: { query }`, `filter-change` с `detail: { filter }`, а также `catalog-reset` и `catalog-retry` без данных. Корень сайта передаётся атрибутом `root`. `course-shell` и `course-navigation` используют `ReactiveElement`, сохраняют исходный HTML и управляют переходом к содержимому, прежними hash-ссылками и мобильным меню. `material-preview` получает область источников через `for="content"` и отображает превью на компьютере.

Контроллеры `catalog-location.js` и `media-query.js` подключают подписки на историю браузера и медиазапросы на время жизни компонента. При отключении каталог отменяет загрузку и показывает весь статический список. Панель поиска и превью используют Light DOM и общий CSS. `src/manifest.js` проверяет манифест версии 2 и фильтрует материалы; `src/preview.js` рассчитывает свободную область для превью с учётом рамки и исходных пропорций изображения. Размеры берутся из загруженной картинки; до загрузки рамка не показывается. Соцсети находятся в шапке и группе «Сообщество» боковой колонки, ссылка на статическую `/license/` завершает навигацию. Локальные иконки Font Awesome Free и официальный текст лицензии находятся в `assets/fontawesome/`. Основное содержание доступно без JavaScript. Светлая и тёмная темы автоматически следуют системной настройке `prefers-color-scheme`, как на CS50; печатная версия всегда светлая.

```bash
npm --prefix utils/site ci
make -f build/Makefile frontend
```

esbuild собирает CSS и JS в `_site/assets/`. Для полной сборки используйте `make -f build/Makefile site`, для проверки — `make -f build/Makefile test`. Новых HTTP API нет: каталог получает статический `materials.json` относительно корня сайта. В URL поиска используется `q`, фильтры сохраняют `#lectures`, `#practices`, `#assignments`.

[Общее руководство](../scripts/README.md) описывает структуру занятий, формат данных и публикацию. Код интерфейса — [MIT](../../LICENSE-MIT); шрифты — OFL, тексты лицензий находятся в `fonts/`.

Черновик учебника доступен только по прямому адресу `/handbooks/`: в общем меню и каталоге ссылок на него нет. На страницах показывается пометка «Черновик», для поисковых роботов задано `noindex, nofollow`. Это не закрытый доступ; материалы ещё требуют доработки и педагогической приёмки.

Учебник использует ту же оболочку и отдельное статическое оглавление. `render-handbook.mjs` преобразует Markdown и формулы во время сборки; зависимости markdown-it, markdown-it-texmath и KaTeX не включаются в браузерный JS. Формулы содержат MathML; стили и шрифты KaTeX находятся в локальных assets. Навигация, текст и решения в `<details>` работают без JavaScript. Оформление чтения находится в общем CSS; поисковый каталог занятий не управляет учебником.
