# Оформление LaTeX

Общие пакеты находятся в `latex/tex/latex/`. Скрипты сборки устанавливают `TEXINPUTS`, поэтому документы подключают пакеты через `\usepackage`, без относительных путей к стилям.

## Презентации

```latex
\usepackage[russian]{academicbeamer}          % лекция, синяя тема
\usepackage[practice,russian]{academicbeamer} % практика, зелёная тема
\setshorttitle{BelOAI \textbar\ Лекция 2}
```

В документе используйте только один вариант подключения. Опции `russian` и `lecture` действуют по умолчанию; `english` включает английский язык, `practice` — тему практик.

Команды темы:

- `\lead{текст}` — короткий акцент; не выделяйте каждое предложение;
- `\tbd{текст}` — отметка черновика;
- `\orient` — отметка «ориентир»;
- `\photoframe{ширина}{высота}{подпись}` — место для изображения;
- `\orientnote[дополнение]` — примечание к ориентировочным значениям.

Белый фон, текстовые блоки без заливок и синий или зелёный акцент. Разделы `\section` не создают отдельные слайды. Примеры компоновки находятся в [шаблоне слайдов](../lectures/_template/slides/README.md).

## Задания

Для математических листов:

```latex
\documentclass[a4paper,11pt]{article}
\usepackage[russian]{academicworksheet}
\setassignmentno{2}
```

Используйте окружение `exercise`, команды `\answerlines{число}` и `\answerbox[высота]` для места под ответ.

Для условий задач по программированию подключите `academicstatement` вместо `academicworksheet`. Индексы в условии и примерах должны начинаться с одной и той же позиции. Доступны окружения `problem`, `io`, `example`, `constraints` и команда `\sampleio{ввод}{вывод}`. Оба пакета поддерживают `russian` (по умолчанию) и `english`.

## Где менять оформление

| Изменение | Файл внутри `latex/tex/latex/` |
| --- | --- |
| Цвета лекций и практик | `beamer/beamercolorthemeAcademic.sty`, `beamer/beamercolorthemeAcademicPractice.sty` |
| Заголовки, колонтитулы и поля | `beamer/beamerouterthemeAcademic.sty` |
| Блоки, списки и команды темы | `beamer/beamerinnerthemeAcademic.sty` |
| Зависимости темы | `beamer/beamerthemeAcademic.sty` |
| Язык и шрифты презентаций | `academicbeamer/academicbeamer.sty` |
| Математические листы | `academicworksheet/academicworksheet.sty` |
| Условия задач | `academicstatement/academicstatement.sty` |

Содержимое занятий храните в папках занятий, а не в стилях. После изменения общих пакетов выполните `make site`, чтобы пересобрать все материалы. Сборка и зависимости описаны в [общем руководстве](../scripts/README.md).

## Читаемость и проверка

Общие стили разрешают переносы и поддерживают ссылки через `\url`. В презентациях текст выравнивается по левому краю; таблицы `tabularx` используйте с текущей `\linewidth` и колонками `Y`. Нумерованные короткие пункты поддерживает `numrows`. Команда `\zebra{номер первой строки}` сохранена для совместимости и задаёт интервал строк без заливки.

Используйте таблицы для сравнения и схемы для связей. Не обрамляйте обычные пояснения блоками и не повторяйте подписи «вопрос» перед вопросами. В таблицах используйте полужирные заголовки и линии `booktabs`.

Не отключайте переносы глобально и не уменьшайте весь слайд ради большого объёма текста. Разделяйте объяснение и упражнение; код размещайте в `frame[fragile]`. Формулы снабжайте обозначениями и единицами измерения. Ответы заданий начинайте с `\clearpage` в конце документа.

Проверьте все страницы после сборки, включая шаблоны (`make tex DIR=lectures/_template`). Успешная компиляция не исключает переполнения или наложения текста.
