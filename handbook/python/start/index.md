Начните здесь, если хотите освоить Python с нуля. Достаточно умения работать с файлами на компьютере и школьной арифметики.

## Как учиться

Читайте объяснение, повторяйте примеры и решайте задачи до открытия решений. «Далее» ведёт по учебнику Python. Необходимые знания указаны перед каждым уроком; знакомые темы можно пропускать.

В прикладных главах этого учебника рассматриваются NumPy, pandas, scikit-learn и PyTorch.

## Где запускать код

Скачайте ноутбук урока и откройте его в [Google Colab](https://colab.research.google.com/) через загрузку файла. Выполняйте ячейки сверху вниз сочетанием Shift+Enter. Свои решения пишите в новых ячейках; готовые решения находятся в конце ноутбука.

Начальные уроки используют стандартную библиотеку. Для работы с данными и моделями см. [общие инструкции по настройке среды](../../start/#среда-и-библиотеки).
