## Как двигаться по учебнику

Открывайте темы через меню или нажимайте «Далее» внизу урока. Перед каждым уроком указаны необходимые знания.

Читайте объяснение, повторяйте примеры и решайте задачи до открытия подсказок. Для перехода дальше достаточно базовых и прикладных задач. Олимпиадные можно оставить на потом.

## Где выполнять примеры

Скачайте ноутбук `.ipynb` из урока и откройте его в [Google Colab](https://colab.research.google.com/) через загрузку файла. Если урок использует [gliders.csv](../data/gliders.csv), загрузите его в файловую панель Colab.

Выполняйте ячейки сверху вниз сочетанием Shift+Enter. Свои решения пишите в новых ячейках рядом с условием; готовые решения находятся в конце ноутбука. Для проверки перезапустите сеанс и выполните всё по порядку.

Первые уроки Python и первый эксперимент ML обходятся без сторонних библиотек. Математику можно изучать без запуска кода. Для остальных примеров достаточно обычного процессора — видеокарта не нужна.

Положите ноутбук и CSV в одну папку. Откройте ноутбук в Jupyter и выберите ядро Python — сеанс, в котором выполняется код. Ячейка — отдельный фрагмент текста или кода; код выполняется сверху вниз, например сочетанием Shift+Enter. Имя, созданное в одной ячейке, доступно в следующих.

Установка пакетов требует интернета. После установки для первых примеров сетевой доступ не нужен.

### Библиотеки для продолжения Python

Уроки до работы с NumPy используют только стандартную библиотеку. Для NumPy, таблиц, scikit-learn, воспроизводимости и PyTorch нужны дополнительные пакеты. Скачайте [список библиотек](requirements.txt) в рабочую папку. В активированной виртуальной среде выполните:

```bash
python -m pip install -r requirements.txt
```

Для примеров с библиотеками используйте Python 3.14 и отдельную виртуальную среду. Примеры работают на обычном процессоре; видеокарта не нужна.

В Colab загрузите `requirements.txt` через файловую панель и выполните отдельную ячейку `%pip install -r requirements.txt`. Если среда попросит, перезапустите сеанс и выполните ноутбук сверху вниз. Установка изменит версии пакетов текущего сеанса. Затем примерам не нужны сеть, ускоритель или внешние модели; данные создаются кодом. Ноутбуки эксперимента с планерами используют скачанный `gliders.csv`, как описано выше.

Математические уроки содержат формулы, рисунки и ручные вычисления: для их изучения запускать Python не требуется. У каждого урока ML есть самостоятельный ноутбук; в концептуальных темах он разбирает кейсы и небольшие вычисления. Механизмы больших моделей показываются на учебных примерах без скачивания внешних весов.

В ноутбуках Python и ML задачи идут перед отдельным разделом решений. Интерактивные примеры с `input` записаны текстом для ручного запуска. Графики строятся прямо в ноутбуке, временные файлы автоматически удаляются.
