# Бумажные планеры: учебные данные

`gliders.csv` — учебный набор из 24 вымышленных объектов. Это придуманные числа, а не результаты измерений или физическая модель полёта.

| Поле | Значение |
| --- | --- |
| `id` | Идентификатор объекта, не признак |
| `span_cm` | Размах крыла, сантиметры |
| `mass_g` | Масса, граммы |
| `flight` | Учебная метка: `короткий` или `дальний` |
| `split` | Фиксированная часть данных: `train`, `validation`, `test` |

Метка задана правилом: размах не меньше 20 см — `дальний`, иначе — `короткий`. В обоих классах есть лёгкие и тяжёлые объекты, чтобы показать влияние масштаба на расстояния. Это не утверждение о статистической независимости массы и класса: числа в таблице заданы авторами, и их распределения по классам могут различаться. Алгоритм KNN получает только обучающие примеры, а не правило генерации.

Обучение: 12 строк; выбор параметров: 6; финальная проверка: 6. Каждая часть содержит оба класса. На таких маленьких и простых данных высокая точность не доказывает пригодность модели для реальных планеров. Не используйте метку, идентификатор или часть данных как вход модели.

## Данные других уроков

Остальные числовые таблицы, короткие фразы, изображения-полосы, графы, вероятности и размеченные кейсы созданы авторами прямо в примерах уроков. Это синтетические данные для проверки конкретных вычислений; они не описывают реальных людей и не служат доказательством качества моделей в реальном мире. Фиксированные вероятности и оценки в концептуальных уроках заданы вручную, а не получены запуском внешней модели.
