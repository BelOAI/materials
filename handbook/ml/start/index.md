## Что находится в хендбуке по ML и как этим пользоваться

Этот хендбук посвящён машинному обучению: от первых экспериментов с данными до классических моделей и нейросетей. В хендбуке шесть разделов. Начните с первого занятия о постановке задачи и проверке простого прогноза.

В оглавлении можно посмотреть назначение каждого раздела и перейти к готовым занятиям. Остальные темы будут добавляться по мере подготовки.

## Для кого

ML-хендбук предназначен для школьников, которые хотят разобраться в машинном обучении или готовятся к BelOAI, а также для учителей и преподавателей, которые планируют обучать школьников ML.

Школьникам он помогает понять, как модели работают с данными и учатся на примерах, освоить основные методы ML и попробовать их в практических задачах.

Учителям и преподавателям он помогает определить, что школьникам нужно знать и уметь в области машинного обучения, в какой последовательности изучать темы и насколько подробно их разбирать. Материалы можно использовать для подготовки и проведения занятий по ML, подбирая объяснения, примеры и задания под уровень учеников.

## От кого

Хендбук подготовлен авторами BelOAI. Список участников проекта доступен в [репозитории](https://github.com/BelOAI/materials/blob/main/CONTRIBUTORS.md).

Материалы открыты: их можно использовать и адаптировать с указанием авторства в соответствии с [лицензией CC BY 4.0](https://github.com/BelOAI/materials/blob/main/LICENSE-CC-BY-4.0).

## Среда и библиотеки

Скачайте ноутбук урока и откройте его в [Google Colab](https://colab.research.google.com/). Выполняйте ячейки сверху вниз сочетанием Shift+Enter. Перед проверкой решения перезапустите сеанс и выполните всё по порядку.

Первый эксперимент использует данные, записанные прямо в ноутбуке. Загружать дополнительные файлы и устанавливать библиотеки для него не нужно. Готовые решения находятся в конце ноутбука.

Для локального запуска установите Python 3.14, создайте виртуальную среду и установите Jupyter:

```bash
python3 -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install jupyter
```

Скачайте [список библиотек](../../start/requirements.txt) и выполните в активированной среде:

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

В Colab загрузите `requirements.txt` и выполните `%pip install -r requirements.txt` в отдельной ячейке. Если среда попросит, перезапустите сеанс. Установка требует интернета; учебные примеры работают на обычном процессоре без скачивания внешних моделей.
