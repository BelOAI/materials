## Как двигаться

Начните с настройки среды, затем переходите к классическому ML, основам глубокого обучения и практическим задачам с нейросетями. Раздел «Как они учатся» объединяет механизмы обучения и анализ экспериментов. Прикладные инструменты вводятся по мере необходимости.

Раздел «Продвинутая математика ИИ» — для обращения по ходу работы, а не входное требование. Ссылки «Перед началом» помогают найти нужное объяснение; они могут вести в другие разделы или учебники. «Далее» остаётся внутри ML. Дополнительные направления читаются отдельными ветками.

## Среда и библиотеки

Скачайте ноутбук урока и откройте его в [Google Colab](https://colab.research.google.com/). Выполняйте ячейки сверху вниз сочетанием Shift+Enter. Перед проверкой решения перезапустите сеанс и выполните всё по порядку.

Для первого эксперимента с планерами загрузите [gliders.csv](../../data/gliders.csv) в файловую панель Colab. Остальные учебные данные создаются в примерах. Готовые решения находятся в конце ноутбука.

Для локального запуска установите Python 3.14, создайте виртуальную среду и установите Jupyter:

```bash
python3 -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install jupyter
```

Скачайте [список библиотек](../../start/requirements.txt) и выполните в активированной среде:

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

В Colab загрузите `requirements.txt` и выполните `%pip install -r requirements.txt` в отдельной ячейке. Если среда попросит, перезапустите сеанс. Установка требует интернета; учебные примеры работают на обычном процессоре без скачивания внешних моделей.
