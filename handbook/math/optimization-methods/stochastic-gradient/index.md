## Чему научимся

Различать полный и случайный градиент и объяснять роль регуляризации.

## Среднее по примерам

Пусть ошибка $L(w)=\frac1n\sum_i\ell_i(w)$, где ℓᵢ — штраф на одном объекте. Полный градиент усредняет все производные и требует просмотра всей выборки. **Стохастический градиент** использует случайно выбранный объект или небольшой мини-пакет. Если объекты выбираются равновероятно, средний по возможным выборам градиент совпадает с полным. Один конкретный шаг при этом может увеличить общую ошибку.

Мини-пакет — группа объектов для одного шага. Он уменьшает случайный разброс оценки градиента по сравнению с одним объектом, но требует больше вычислений. Проход по всем обучающим объектам называют эпохой.

## Разобранный пример: два разных совета

Ошибки объектов ℓ₁(w)=(w−1)² и ℓ₂(w)=(w−5)². При w=0 их градиенты −2 и −10, полный средний градиент −6. Шаг η=0.1 даёт w=0.6; случайный шаг только по первому дал бы 0.2, только по второму — 1.0. Среднее двух возможных результатов тоже 0.6.

Не выбирайте всегда удобный первый объект: тогда оценка градиента смещается к нему. Перемешивание порядка и явный seed помогают повторять опыт, но не делают каждый шаг монотонным.

## Ограничиваем сложность

Регуляризация добавляет к обучающей ошибке штраф на параметры: $J(w)=L(w)+\lambda\|w\|_2^2$, λ≥0. Для одной координаты добавочный градиент равен 2λw. При положительном w он тянет параметр к нулю, при отрицательном — тоже к нулю. Это предпочтение меньших коэффициентов, а не дополнительные измерения.

Если L(w)=(w−3)², λ=1, то J′(w)=2(w−3)+2w=4w−6. Минимум сместился с 3 к 1.5. Регуляризация намеренно допускает большую ошибку на обучении ради другого компромисса. Её силу выбирают на проверочных данных внутри разработки, не по итоговому тесту.

Данные разработки делят на обучающую часть и **validation**, проверочную часть для выбора настроек, например λ. При перекрёстной проверке несколько таких разбиений чередуют. Итоговый тест оставляют для одной оценки уже выбранного решения: если выбирать λ по нему, он тоже превратится в часть разработки.

## Типичные ошибки

Не смешивайте сумму и среднее ошибок: это меняет относительную силу штрафа. Шум шага не равен ошибке реализации.

### 5. Олимпиадная
Почему выбор только объектов с большой текущей ошибкой может изменить оценку полного среднего градиента? Разберите две ошибки ℓ₁(w)=(w−1)² и ℓ₂(w)=(w−5)² при w=0.

<details>
<summary>Подсказка</summary>

Изменились веса объектов в среднем.

</details>

<details>
<summary>Решение</summary>

При w=0 ошибки равны 1 и 25, градиенты −2 и −10. При равновероятном выборе средний градиент $(−2−10)/2=−6$, он совпадает с градиентом полной средней ошибки. Если всегда выбирать только второй, более трудный объект, получаем −10. Изменились веса объектов в оценке. Иногда разные способы выбора могут случайно дать один результат, но совпадения в общем случае уже нет.

</details>
