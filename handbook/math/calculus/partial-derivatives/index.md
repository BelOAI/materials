## Чему научимся

Вычислять частные производные и связывать компоненты градиента с изменением параметров.

## Частная производная и градиент

Функция $L(w_1,w_2)$ имеет два входа и один выход. Частная производная по $w_1$ вычисляется при фиксированном $w_2$. Знак $\partial$ отличает частную производную от обычной производной функции одного входа. Например, для $L=w_1^2+3w_2^2$, вычисляя производную по $w_1$, считаем $3w_2^2$ константой и получаем $\partial L/\partial w_1=2w_1$, $\partial L/\partial w_2=6w_2$.

Градиент $\nabla L$ — столбец частных производных в порядке параметров. Верхний индекс $T$ меняет строку на столбец и наоборот. В точке $(1,2)$ градиент равен $(2,12)^T$: это столбец с компонентами 2 и 12. Символ $\Delta$ обозначает изменение, $\approx$ — приближённое равенство. Рассматриваем дифференцируемые функции: рядом с точкой их изменение можно приближённо описать линейным выражением. Для малого вектора изменения $\Delta w$:

$$L(w+\Delta w)\approx L(w)+\nabla L(w)^T\Delta w.$$

Например, при $w=(1,2)$ и $\Delta w=(0.01,0)$ ожидаем изменение $2\cdot0.01+12\cdot0=0.02$. Точное изменение функции $w_1^2+3w_2^2$ равно $1.01^2-1=0.0201$. Приближение полезно для маленьких, а не произвольных изменений. Направление против градиента уменьшает функцию при достаточно малом шаге и ненулевом градиенте. Большой шаг может увеличить её; выбор шага изучается в оптимизации.

## Разобранный пример: ошибка линейной модели

Пусть $X$ — таблица $n\times d$, $w$ — столбец $d\times1$, $y$ — столбец ответов $n\times1$. Обозначим знаковую ошибку $e=Xw-y$ — вектор разностей между предсказаниями и ответами. Его $i$-я компонента — $e_i$, признак объекта $i$ в столбце $j$ — $X_{ij}$. Для $n>0$ средняя квадратичная ошибка:

$$L(w)=\frac1n\sum_{i=1}^{n}e_i^2,\qquad
\frac{\partial L}{\partial w_j}=\frac2n\sum_{i=1}^{n}e_iX_{ij},\qquad
\nabla L(w)=\frac2n X^T(Xw-y).$$

Почему появляется $X_{ij}$? Производная ошибки объекта $i$ по весу $w_j$ равна этому признаку; квадрат даёт множитель $2e_i$, затем складываем вклады и делим на $n$.

Для одного объекта $x=(2,1)$, $y=5$ и $w=(1,1)$ предсказание равно 3, знаковая ошибка −2, её квадрат 4. Градиент $2(-2)(2,1)=(-8,-4)$. Малое увеличение обоих весов приблизит ответ к 5.

Если добавить свободный член $b$, то $e_i=x_i\cdot w+b-y_i$ и $\partial L/\partial b=(2/n)\sum_i e_i$. Не включайте $b$ дважды — и отдельным числом, и дополнительным столбцом единиц.

## Разобранный пример: два независимых изменения

Для $L(a,b)=a^2+ab$ частная производная по a равна $2a+b$: при изменении a число b фиксировано. По b получаем a. В точке (2, 3) градиент равен (7, 2). Малое изменение только a на h даёт примерно 7h, только b — 2h, обоих одновременно — 9h.

Нельзя сравнивать число, полученное при изменении обоих параметров, с каждой компонентой отдельно. Компонента отвечает на вопрос об изменении одной координаты при фиксированных остальных.

## Разобранный пример: одна точка, разные направления

Для L(a,b)=a²+ab при (2,3) градиент (7,2). Шаг Δ=(0.01,−0.02) даёт линейное изменение 7·0.01+2·(−0.02)=0.03. Точное значение в новой точке равно 2.01²+2.01·2.98=10.0299 вместо 10; изменение 0.0299 близко к предсказанному.

Если изменить только a, используется первая компонента; только b — вторая. Градиент не является списком двух обязательных независимых обновлений: скалярное произведение с выбранным направлением объединяет их вклады. Единицы координат влияют на размер компонентов, поэтому сравнение «какой параметр важнее» требует осторожности.

## Типичные ошибки

При одной частной производной сохраняйте остальные входы. Не пропускайте деление на число объектов в средней ошибке и не включайте свободный член дважды.

## Задачи

### 1. Базовая

Что фиксируется при частной производной по первому параметру?

<details>
<summary>Подсказка</summary>

Остальные входы не меняются.

</details>

<details>
<summary>Решение</summary>

Все остальные входные параметры считаются постоянными; изменяется только выбранная координата.

</details>

### 2. Базовая

Сколько компонент у градиента функции трёх параметров?

<details>
<summary>Подсказка</summary>

По одной на вход.

</details>

<details>
<summary>Решение</summary>

Три — по одной частной производной на каждый входной параметр.

</details>

### 3. Прикладная

Найдите градиент a²+ab при (2, 3).

<details>
<summary>Подсказка</summary>

Возьмите производную по каждой переменной, удерживая другую постоянной; лишь затем подставьте точку.

</details>

<details>
<summary>Решение</summary>

Производная по a равна 2a+b, по b — a. В точке (2,3) получаем (7,2).

</details>

### 4. Прикладная

Для x=(2,1), y=5 найдите градиент квадрата ошибки при w=(2,1).

<details>
<summary>Подсказка</summary>

Сначала разность предсказания и ответа.

</details>

<details>
<summary>Решение</summary>

Предсказание 5, знаковая ошибка 0, градиент (0, 0).

</details>

### 5. Олимпиадная

Почему пропуск деления на n не обнаруживается на одном объекте?

<details>
<summary>Подсказка</summary>

При n=1 множитель равен 1.

</details>

<details>
<summary>Решение</summary>

Нужен набор с несколькими объектами. Повторение одного объекта дважды не должно менять градиент средней ошибки.

</details>

### 6. Олимпиадная

Всегда ли большой шаг против градиента уменьшает ошибку?

<details>
<summary>Подсказка</summary>

Линейное приближение локально.

</details>

<details>
<summary>Решение</summary>

Нет. Для x² в точке 1 слишком большой шаг может перевести в −3 и увеличить значение с 1 до 9.

</details>

## Итоги

Частная производная меняет одну переменную при фиксированных остальных. Градиент собирает эти скорости в столбец и позволяет оценить изменение функции на малом векторном шаге.

## Самопроверка

Посчитайте линейное и точное изменения. Почему одновременный сдвиг нельзя сравнивать с одной частной производной?

Для перехода дальше достаточно базовых и прикладных задач; олимпиадные можно отложить.
