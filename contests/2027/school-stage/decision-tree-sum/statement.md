Для каждой целочисленной точки $(x,y)$, где $0\le x,y<100$, дерево выдаёт ответ согласно таблице.

*Таблица 1 — Ответ дерева в четырёх областях*

| Условие | Ответ |
| :--- | ---: |
| $x<20$, $y<30$ | 1 |
| $x<20$, $y\ge 30$ | 2 |
| $x\ge 20$, $y<30$ | −1 |
| $x\ge 20$, $y\ge 30$ | 3 |
