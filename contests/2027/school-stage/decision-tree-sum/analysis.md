Разделим квадрат из 10 000 точек на четыре прямоугольника. В каждом прямоугольнике ответ дерева одинаковый, поэтому достаточно умножить число точек области на её ответ.

При $x<20$ есть 20 значений $x$, а при $x\ge20$ — 80. Для $y<30$ есть 30 значений, для $y\ge30$ — 70. Тогда

$$20\cdot30\cdot1+20\cdot70\cdot2+80\cdot30\cdot(-1)+80\cdot70\cdot3=17\,800.$$

Строгие и нестрогие неравенства в таблице относят каждую точку ровно к одной области.

**Ответ: 17800.**

<details><summary>Код Python</summary>

```python
total = 0
for x in range(100):
    for y in range(100):
        if x < 20:
            answer = 1 if y < 30 else 2
        else:
            answer = -1 if y < 30 else 3
        total += answer

print(total)
```
