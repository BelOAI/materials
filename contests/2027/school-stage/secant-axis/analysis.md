Вычислим значения функции на концах отрезка:

$$f(1)=2-3{,}4=-1{,}4,\qquad f(2)=4-3{,}4=0{,}6.$$

Между точками отрезок поднимается на $0{,}6-(-1{,}4)=2$. Чтобы из левой точки подняться до оси $Ox$, нужно вертикальное приращение $1{,}4$, то есть $1{,}4/2=0{,}7$ полного подъёма. Вдоль прямого отрезка вертикальное приращение пропорционально горизонтальному, поэтому по оси $x$ проходим ту же долю. Абсцисса увеличивается от 1 до 2, поэтому точка пересечения имеет абсциссу $1+0{,}7=1{,}7$.

**Ответ: 1,7.** Здесь ищется нуль линейного отрезка между точками, а не решение уравнения $2^x-3{,}4=0$.

<details><summary>Код Python</summary>

```python
left_x, right_x = 1, 2
left_y = 2**left_x - 3.4
right_y = 2**right_x - 3.4

zero_x = left_x + (0 - left_y) * (right_x - left_x) / (right_y - left_y)
print(f"{zero_x:.1f}".replace(".", ","))
```
