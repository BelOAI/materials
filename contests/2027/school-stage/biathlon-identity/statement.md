В таблицах собрана статистика биатлонистов за первый триместр нескольких сезонов. В таблице последнего сезона имена скрыты. Предскажите имя спортсмена для каждой строки, используя статистику и примеры из предыдущих сезонов.

### Данные

Каждая строка описывает выступления одного спортсмена в одной дисциплине за первый триместр сезона. Если спортсмен участвовал в нескольких дисциплинах, за сезон ему соответствуют несколько строк. Строки в таблицах перемешаны.

Скачайте [архив с ноутбуком и исходными данными](https://new.contest.yandex.ru/contests/101501/problems?id=7993389%2F2026_11_15%2F3nX6ZSXjMe) и распакуйте его. В папке `data/` будут файлы:

- `train.csv` — сезоны 2016/17–2023/24, с известными именами;
- `validation.csv` — сезон 2024/25, с известными именами для локальной проверки;
- `test.csv` — сезон 2025/26, без имён.

Столбцы таблиц:

- `season_end` — год окончания сезона: например, `2025` для сезона 2024/25;
- `country` — код страны;
- `gender` — категория гонки: `M` или `F`;
- `discipline` — `SP` (спринт), `IN` (индивидуальная гонка), `PU` (преследование), `MS` (масс-старт);
- `misses_per_race` — среднее число промахов за гонку;
- `shooting_time_s` — среднее время стрельбы за один визит на рубеж, в секундах;
- `races` — число гонок, по которым рассчитана статистика.

Например, строка `2025,ITA,F,SP,1.5,28.0,2` описывает условные результаты спортсменки из Италии в спринте. За первый триместр сезона 2024/25 учтены две гонки: в среднем 1,5 промаха за гонку и 28 секунд на один визит на рубеж.

`label` — имя спортсмена. Если у разных спортсменов совпадают имена, к ним добавлен код страны. Все имена из валидационной таблицы встречаются в обучающей; каждое имя из тестовой таблицы встречается в обучающей или валидационной.

### Отправка решения

В распакованной папке выполните `python -m pip install -r starter/requirements.txt`. Откройте `starter.ipynb` в Jupyter и запустите ячейки сверху вниз, чтобы проверить стартовое решение на сезоне 2024/25.

Сохраните код из ячейки «Код решения для отправки» в файл `solution.py` или используйте `starter/solution.py`. В редакторе Яндекс Контеста выберите `(make) yandexdataschool`, нажмите значок скрепки, прикрепите `solution.py` и нажмите «Отправить». Отправьте один файл Python `solution.py` без архива. Выданный `starter/solution.py` можно отправить без изменений; совпадения с предоставленным стартовым кодом разрешены. Стартовое правило выбирает самое частое имя для сочетания страны, пола и дисциплины. Попробуйте улучшить его, учитывая среднее время стрельбы и число промахов, а затем сравните оба решения на сезоне 2024/25.

В `solution.py` должна быть функция `predict(train, test)`. Оба аргумента имеют тип `pandas.DataFrame`. Проверяющая программа объединяет `train.csv` и `validation.csv` и передаёт объединённую таблицу в `train`. В `test` поступают строки оцениваемой части сезона 2025/26. В обеих таблицах есть семь перечисленных столбцов, а в `train` также есть `label`. Строки внутри переданных таблиц можно анализировать совместно.

Функция должна вернуть список или одномерный массив строк — по одной метке из `train['label']` на каждую строку `test`, сохранив исходный порядок строк. Если хотя бы одна предсказанная метка отсутствует в `train['label']`, за эту часть начисляется 0 баллов. Для локальной проверки используйте `train.csv` как обучающую таблицу, а из `validation.csv` удалите `label` перед вызовом функции. Не используйте эти метки до получения предсказаний.

### Оценивание

Качество измеряется метрикой **Macro-F1**. Для каждого имени среди правильных ответов оцениваемой части считаются TP — верные предсказания этого имени, FP — предсказания этого имени для другого спортсмена, FN — случаи, когда правильное имя спортсмена предсказано неверно.

$$F1 = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}.$$

Macro-F1 — среднее значение F1 по именам из правильных ответов оцениваемой части. Таким образом, каждое имя имеет одинаковый вес. Балл за каждую часть вычисляется по формуле

$$100 \cdot \min\left(\frac{\operatorname{Macro-F1}}{0{,}75}, 1\right).$$

При Macro-F1 от 0,75 включительно начисляется 100 баллов. Ниже этого порога шкала линейная: Macro-F1 = 0,375 даёт 50 баллов, а все верные имена дают 100.

Например, правильные имена — Анна, Анна и Борис, а решение во всех трёх строках предсказало Анну. Для Анны TP = 2, FP = 1 и FN = 0, поэтому её F1 равна `4/5`. Для Бориса TP = 0, FP = 0 и FN = 1, поэтому его F1 равна 0. Macro-F1 равна `(4/5 + 0) / 2 = 0,4`, а балл за эту часть — `100 × 0,4 / 0,75 ≈ 53,33`.

### Публичная и скрытая части

Строки тестовой таблицы сезона 2025/26 случайным образом разделены на публичную и скрытую части. Каждая посылка проверяется сразу на обеих частях. Macro-F1 и соответствующий ей балл вычисляются отдельно для каждой части. Итоговый результат — 20% балла за публичную часть и 80% балла за скрытую, максимум 100. Чтобы получить 100 баллов за задачу, Macro-F1 должна быть не ниже 0,75 в обеих частях.

Исходные сезонные показатели взяты из [Real Biathlon](https://www.realbiathlon.com/seasons.html), основной источник результатов — [IBU Datacenter](https://www.biathlonresults.com/). Проверка проходит офлайн.
