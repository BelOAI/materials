Если выбирать минимум в каждой строке независимо, получится нижняя граница $2+2+1+2=7$. Для первого и третьего пассажиров эти минимумы относятся к одному такси T2. Первому пассажиру любое другое такси добавляет как минимум 2 минуты, а третьему — как минимум 2 минуты. Следовательно, при назначении разных такси сумма составляет не менее $7+2=9$ минут.

Назначим П1 такси Т1, П2 — Т3, П3 — Т2, П4 — Т4. Сумма $4+2+1+2=9$ минут достигает нижней границы. Код проверяет это полным перебором $6\cdot5\cdot4\cdot3=360$ назначений.

**Ответ: 9.**

<details><summary>Код Python</summary>

```python
from itertools import permutations

minutes = [
    [4, 2, 7, 9, 8, 6],
    [3, 5, 2, 8, 7, 9],
    [6, 1, 4, 3, 8, 7],
    [8, 6, 5, 2, 3, 4],
]

best = min(
    sum(minutes[passenger][taxi]
        for passenger, taxi in enumerate(assignment))
    for assignment in permutations(range(6), 4)
)
print(best)
```
