Составьте рейтинг десяти самых результативных игроков мужского чемпионата мира по футболу 2026 года. Для каждого игрока рассчитайте очки по голам и голевым передачам и запишите итоговый рейтинг в CSV.

### Данные

Скачайте архив с таблицей игроков на странице [оригинального условия](https://new.contest.yandex.ru/contests/101501/problems?id=7993389%2F2026_11_15%2F6ws3kERrnp) и распакуйте его. В `data/players.csv` приведены 50 игроков; все участники итоговой десятки есть в таблице. Строки перемешаны. Первая строка содержит заголовки столбцов:

- `player` — имя игрока;
- `country` — страна;
- `minutes_played` — число сыгранных минут;
- `goals` — число забитых голов;
- `assists` — число голевых передач.

Все числовые значения целые и неотрицательные, кроме `minutes_played`, которое больше нуля.

Для каждого игрока вычислите `score = 3 × goals + assists`: за гол начисляется 3 очка, за голевую передачу — 1 очко. Сначала упорядочьте игроков по убыванию `score`. При равном счёте выше ставьте игрока, забившего больше голов; затем сравните число сыгранных минут по возрастанию. Если равенство сохранилось, сравните `player`, а затем `country` по возрастанию. Имена и страны сравниваются посимвольно по кодам Unicode с учётом регистра, как строки Python 3.

Выберите первые десять строк после сортировки. Пронумеруйте их от 1 до 10.

### Формат ответа

Подготовьте архив `submission.zip` с единственным файлом `top10.csv` в корне. В редакторе Яндекс Контеста выберите `(make) yandexdataschool`, нажмите скрепку, прикрепите `submission.zip` и нажмите «Отправить».

Запишите CSV в кодировке UTF-8 с запятой как разделителем. После заголовка должно быть ровно десять строк. Переносите имена и страны из исходной таблицы в том же написании. Все числовые столбцы должны содержать целые числа.

Заголовок CSV:

```csv
rank,player,country,minutes_played,goals,assists,score
```

### Пример

Рассмотрим вымышленную таблицу из трёх игроков.

```csv
player,country,minutes_played,goals,assists
Bruno,Spain,180,2,0
Carlo,Italy,120,2,1
Alex,France,300,1,3
```

После начисления очков и сортировки получится такой порядок.

```csv
rank,player,country,minutes_played,goals,assists,score
1,Carlo,Italy,120,2,1,7
2,Bruno,Spain,180,2,0,6
3,Alex,France,300,1,3,6
```

У Бруно и Алекса по 6 очков. Сначала сравниваются голы, поэтому Бруно с двумя голами идёт раньше Алекса с одним, хотя у Алекса больше голевых передач. В приложенной таблице ответа нужно указать десять строк данных.

### Оценивание

За игрока из эталонной десятки с верными страной, числом минут, голами, передачами и очками начисляется `10 − |место в ответе − место в эталоне|` баллов. Например, игрок с третьего места, поставленный на пятое, приносит 8 баллов. Игрок вне эталонной десятки или строка с неверными данными приносит 0 баллов.

Баллы за строки складываются. Максимум — 100 баллов за точный рейтинг. Если поменять местами только двух первых игроков, получится 98 баллов. Место определяется порядком строк, поэтому значения `rank` должны идти от 1 до 10. Каждая пара `player,country` может встретиться только один раз. Нарушение формата даёт 0 баллов за посылку.

Голы, голевые передачи и игровое время взяты из таблиц [FotMob: голы](https://www.fotmob.com/en-GB/leagues/77/stats/season/24254/players/goals/world-cup), [передачи](https://www.fotmob.com/en-GB/leagues/77/stats/season/24254/players/goal_assist/world-cup) и [игровое время](https://www.fotmob.com/en-GB/leagues/77/stats/season/24254/players/mins_played/world-cup). Турнир указан в каталоге [статистики FIFA](https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/statistics/player-statistics?searchOverlay=1). Данные сохранены в ресурсах задачи, чтобы проверка работала без сети.
