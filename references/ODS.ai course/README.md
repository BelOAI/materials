# ODS.ai: классические модели ML

[Оригинальный курс, осень 2026](https://ods.ai/tracks/classic-models-autumn26).

Курс посвящён моделям для табличных данных. Основные темы: линейная и логистическая регрессия, оценка качества и подбор модели, деревья, случайный лес и бустинг. Также рассматриваются интерпретация результатов, A/B-тесты, кластеризация и снижение размерности.

Для подготовки хендбука полезны последовательность тем и примеры связи модели с практической задачей. Учебные файлы курса доступны у авторов по ссылке выше.
