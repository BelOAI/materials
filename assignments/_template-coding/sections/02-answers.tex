\section*{Разбор для самопроверки}
Для каждого $a_j$ ищите значение $t-a_j$ среди уже просмотренных элементов. Храните значение и его индекс в словаре. Сначала выполняйте поиск, затем добавляйте текущий элемент: так один индекс не используется дважды.

В среднем требуется $O(n)$ времени и $O(n)$ памяти. При найденной паре выведите индексы с единицы; иначе --- \texttt{-1 -1}.

Проверьте случаи: пара есть; пары нет; два одинаковых числа дают нужную сумму; один элемент нельзя использовать дважды.
