# Инструкции для агентов

Репозиторий содержит материалы подготовки к BelOAI и статический сайт: <https://beloai.github.io/materials/>. Документация и тексты интерфейса — на русском. Пишите кратко, без повторения общих инструкций.

## Где что находится

- `lectures/`, `practices/`, `assignments/` — лекции, практики и домашние задания; у каждого материала своя папка с `meta.yaml`.
- `main.tex` подключает содержимое из `slides/` или `sections/`; порядок задают команды `\input`.
- `materials/` и `assets/` внутри папки занятия — дополнительные файлы и изображения.
- `latex/tex/latex/` — общие стили LaTeX. Содержимое занятий сюда не помещайте.
- `scripts/` — сборка и генератор манифеста; `site/` — интерфейс Lit, CSS и шрифты.
- `_site/` — результат сборки: HTML, `materials.json`, интерфейс, PDF, превью и дополнительные файлы.

## Обязательные правила

1. Главный README предназначен ученикам. Технические инструкции размещайте в [руководстве по сборке](scripts/README.md) и README разделов.
2. Вид материала определяется родительской папкой. Нумерация лекций, практик и заданий независима; номер папки не задаёт порядок на сайте.
3. Папки с префиксом `_` и материалы с `build: false` пропускаются при общей сборке. `hidden: true` скрывает запись, но не отключает сборку файлов.
4. Лекции используют `academicbeamer`, практики — его опцию `practice`; задания — класс `article` и пакет `academicworksheet` или `academicstatement`. Подключайте пакеты через `\usepackage`, а не относительный `\input`.
5. Для заданий обязателен `assignment_type: math` или `coding`. Для новых публичных материалов укажите `build: true`, настоящую дату и рабочие ссылки для учеников.
6. Python публикует манифест, Lit отображает список. При изменении формата согласованно обновляйте генератор, проверку манифеста, интерфейс и тесты.
7. Не коммитьте `_site/`, `main.pdf`, вспомогательные файлы LaTeX, `node_modules/` и результаты проверки браузером. Сохраняйте окончания строк LF.
8. Сохраняйте разделение лицензий; официальные тексты лицензий не переводите и не изменяйте. Подробнее: [лицензирование](LICENSING.md).

## Проверка изменений

- Изменение занятия: `make session DIR=lectures/02-topic` (подставьте нужный путь), затем `make site`.
- Изменение интерфейса или генератора: `make test`, `make site`, проверка в браузере.
- Изменение общего стиля LaTeX: пересоберите все материалы через `make site`.
- Проверьте порядок записей, фильтры и hash-ссылки, доступность файлов, мобильную вёрстку и клавиатурное управление.
- Перед завершением проверьте `git diff --check` и `git status`. Если проверка не выполнена, укажите причину.

Зависимости, поля метаданных и публикация описаны в [scripts/README.md](scripts/README.md). Особенности: [лекции](lectures/README.md), [практики](practices/README.md), [задания](assignments/README.md), [LaTeX](latex/README.md).
