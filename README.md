# Материалы подготовки к BelOAI

Лекции, практики и домашние задания для подготовки к олимпиаде по искусственному интеллекту.

**[Открыть сайт с материалами](https://beloai.github.io/materials/)**

На сайте материалы собраны по учебным неделям: неделя 0 «Математическая подготовка» и неделя 1 «Введение в машинное обучение». На странице недели перечислены доступные материалы. Найти конкретную тему можно в разделе «Все материалы» — через поиск и фильтры.

## Как пользоваться

- **PDF** — откройте или скачайте слайды и домашние задания.
- **Ноутбуки** — просмотрите HTML-версию в браузере или скачайте `.ipynb` для Jupyter или Google Colab.

Страницы курса и ссылки на материалы доступны без JavaScript; для поиска и фильтров он нужен. Исходные материалы также доступны в папках [лекций](lectures/), [практик](practices/) и [заданий](assignments/).
