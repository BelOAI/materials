## Учебник по машинному обучению

Учебник пока находится в разработке. В нём путь от первых экспериментов с данными до моделей и нейросетей; уроки включают объяснения, примеры и задачи для самостоятельной работы. Для начала нужны основы Python и школьная математика — необходимые темы можно повторять по ссылкам внутри учебника.

**[Открыть учебник по МЛ →](https://materials.beloai.by/handbook/ml/)**

Чтобы выбрать тему, используйте оглавление учебника. Чтобы идти по порядку, начните с [введения](handbook/ml/start/index.md) и переходите по ссылке «Далее» внизу урока. К урокам доступны ноутбуки `.ipynb`: их можно скачать и выполнить в Jupyter или Google Colab. Подробности о маршруте и подготовке среды — в [README учебника](handbook/ml/README.md).

## Занятия по неделям

На [сайте занятий](https://beloai.github.io/materials/) откройте нужную неделю или найдите тему в разделе «Все материалы». На странице материала можно открыть или скачать PDF, а для практики — просмотреть ноутбук в браузере или скачать `.ipynb`.

Исходники разложены по видам: [лекции](lectures/), [практики](practices/) и [домашние задания](assignments/). Список доступных недель и файлов смотрите на сайте: он обновляется вместе с публикацией материалов.
