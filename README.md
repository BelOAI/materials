# BelOAI — Белорусская олимпиада по искусственному интеллекту

Здесь публикуются **презентации к занятиям** BelOAI: слайды в формате PDF, которые можно просматривать онлайн или скачать.

## Где смотреть занятия

**Сайт с презентациями:** [beloai.github.io/materials](https://beloai.github.io/materials/)

На главной странице — список занятий с описанием, датой и превью первого слайда. Нажмите на карточку или ссылку **«Скачать PDF»**, чтобы открыть или сохранить файл.

## Доступные занятия

Опубликованные занятия появляются на [сайте](https://beloai.github.io/materials/) после публикации материалов организаторами.

## Как пользоваться PDF

- **На компьютере или планшете** — откройте PDF в браузере или в любом просмотрщике (Preview, Adobe Reader и т.п.).
- **На телефоне** — скачайте файл и откройте в приложении для PDF; для удобства можно добавить закладку на сайт.
- **Для конспекта** — слайды рассчитаны на формат 16:9; при печати выберите «уместить на странице» или печать нескольких слайдов на лист, если нужен бумажный вариант.

## Вопросы по материалам

Если ссылка не открывается, файл не скачивается или вы не нашли нужное занятие — подождите, пока отработает GitHub Actions и соберётся материал. Если не помогло — обращайтесь к организаторам BelOAI.
