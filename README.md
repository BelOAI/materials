# Материалы подготовки к BelOAI

[Учебник по ML](https://materials.beloai.by/handbook/ml/) · [Занятия по неделям](https://beloai.github.io/materials/)

Учебник в разработке. Для начала нужны основы Python и школьная математика. Начните с [введения](handbook/ml/start/index.md). Ноутбуки `.ipynb` можно выполнять в Jupyter или Google Colab.
