# Материалы подготовки к BelOAI

Здесь есть два способа учиться: читать учебник по машинному обучению в своём темпе или открывать материалы занятий по неделям.

| Если вы хотите… | Начните здесь |
| --- | --- |
| Последовательно изучать машинное обучение | [Учебник по МЛ](https://materials.beloai.by/handbooks/ml/) · [Введение и подготовка](handbooks/ml/00-intro/content.md) |
| Найти материалы конкретной недели | [Сайт занятий](https://materials.beloai.by/) |
| Открыть исходные файлы в репозитории | [Учебник](handbooks/ml/) · [Занятия по неделям](course/) |

## Учебник по машинному обучению

Учебник находится в разработке: доступны введение и [первое занятие](handbooks/ml/01-classic-ml/01-first-experiment/content.md); остальные материалы готовятся. Для начала нужны основы Python и школьная математика.

**[Открыть учебник по МЛ →](https://materials.beloai.by/handbooks/ml/)**

Начните с [введения](handbooks/ml/00-intro/content.md). Оглавление и подготовка среды описаны в [README учебника](handbooks/ml/README.md).

## Занятия по неделям

На [сайте занятий](https://materials.beloai.by/) откройте нужную неделю или найдите тему в разделе «Все материалы». На странице материала можно открыть или скачать PDF, а для практики — просмотреть ноутбук в браузере или скачать `.ipynb`.

Исходники собраны [по неделям](course/): лекция, практики и домашние задания каждой темы находятся рядом. Лекцию можно листать прямо на странице недели. Список доступных недель и файлов смотрите на сайте: он обновляется вместе с публикацией материалов.

Для авторов материалов: [добавление и публикация](utils/scripts/README.md) · [оформление LaTeX](utils/latex/README.md).
