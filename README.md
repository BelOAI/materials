# Материалы к занятиям по подготовке к олимпиаде по искусственному интеллекту

Здесь публикуются **материалы к занятиям** для участников Олимпиады по искусственному интеллекту (BelOAI): слайды лекций и практик в PDF, ноутбуки Jupyter, файлы для скачивания и ссылки на задания (Яндекс.Контест, Kaggle и др.).

## Где смотреть занятия

**Сайт с материалами:** [beloai.github.io/materials](https://beloai.github.io/materials/)

На главной странице — список лекций и практик в порядке дат (сначала ближайшие). У каждого занятия — описание, дата и превью (если есть слайды). Лекции и практики отличаются по цвету карточки.

## Доступные занятия

Опубликованные занятия появляются на [сайте](https://beloai.github.io/materials/) после публикации материалов организаторами.

## Как пользоваться материалами

- **PDF** — откройте в браузере или скачайте в любой программе для просмотра.
- **Jupyter Notebook** — нажмите «Открыть ноутбук» для просмотра в браузере или скачайте `.ipynb` для Google Colab / Jupyter.
- **Яндекс.Контест и другие ссылки** — откроются на соответствующем сайте в новой вкладке.

Если ссылка не открывается, файл не скачивается или вы не нашли нужное занятие — подождите, пока отработает GitHub Actions и соберётся материал. Если не помогло — обращайтесь к организаторам BelOAI.
