# Интерфейс сайта

Python генерирует главную, страницы недель и каталог из `course.json` и метаданных материалов. `index.html` — общий HTML-шаблон, `src/site.css` — оформление по компоновке CS50: тёмно-золотистая колонка 320 px, логотип Unbounded, основной текст PT Sans и вложенные списки ресурсов. До 992 px навигация переносится в верхний блок с раскрываемым меню. PT Sans поставляется локально в обычном и жирном начертании вместе с OFL.

`src/materials-app.js` регистрирует компоненты Lit. `materials-catalog` загружает манифест и фильтрует только вложенный статический список; `catalog-controls` получает состояние через свойства и отправляет события `query-change` с `detail: { query }`, `filter-change` с `detail: { filter }`, а также `catalog-reset` и `catalog-retry` без данных. Корень сайта передаётся атрибутом `root`. `course-shell` и `course-navigation` используют `ReactiveElement`, сохраняют исходный HTML и управляют переходом к содержимому, прежними hash-ссылками и мобильным меню. `material-preview` получает область источников через `for="content"` и отображает превью на компьютере.

Контроллеры `catalog-location.js` и `media-query.js` подключают подписки на историю браузера и медиазапросы на время жизни компонента. При отключении каталог отменяет загрузку и показывает весь статический список. Панель поиска и превью используют Light DOM и общий CSS. `src/manifest.js` проверяет манифест версии 2 и фильтрует материалы; `src/preview.js` рассчитывает свободную область для превью с учётом рамки и исходных пропорций изображения. Размеры берутся из загруженной картинки; до загрузки рамка не показывается. Соцсети находятся в шапке и группе «Сообщество» боковой колонки, ссылка на статическую `/license/` завершает навигацию. Локальные иконки Font Awesome Free и официальный текст лицензии находятся в `assets/fontawesome/`. Основное содержание доступно без JavaScript. Светлая и тёмная темы автоматически следуют системной настройке `prefers-color-scheme`, как на CS50; печатная версия всегда светлая.

```bash
npm --prefix site ci
make frontend
```

esbuild собирает CSS и JS в `_site/assets/`. Для полной сборки используйте `make site`, для проверки — `make test`. Новых HTTP API нет: каталог получает статический `materials.json` относительно корня сайта. В URL поиска используется `q`, фильтры сохраняют `#lectures`, `#practices`, `#assignments`.

[Общее руководство](../scripts/README.md) описывает структуру курса, формат данных и публикацию. Код интерфейса — [MIT](../LICENSE-MIT); шрифты — OFL, тексты лицензий находятся в `fonts/`.
