# Интерфейс сайта

`src/materials-app.js` содержит два компонента Lit: приложение загружает `materials.json` и управляет фильтрами, строка отображает один материал. `src/manifest.js` проверяет данные и форматирует подписи. Оформление находится в `src/site.css`, оболочка страницы — в `index.html`.

```bash
npm --prefix site ci
make frontend
```

esbuild собирает CSS и JS в `_site/assets/`. Генератор копирует оболочку и шрифты, публикует манифест. Для полной сборки используйте `make site`, для проверки — `make test`.

Новых HTTP API нет: сайт получает статический манифест по относительному адресу `materials.json`. Отключённый JavaScript оставляет пояснение и ссылку на репозиторий.

[Общее руководство](../scripts/README.md) описывает формат данных, локальный просмотр и публикацию. Код интерфейса — [MIT](../LICENSE-MIT); шрифты — OFL, тексты лицензий находятся в `fonts/`.
