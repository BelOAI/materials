# Работаем с текстом готовой моделью

Один и тот же текст можно классифицировать по тональности или представить вектором для поиска похожих фраз. Проверяем отрицание, неоднозначность и перенос на белорусский язык.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема](media/text-tasks.svg)

Для примеров нужны PyTorch, Transformers, Sentence Transformers, pandas и scikit-learn. Первое обращение к моделям скачивает веса.
