# Генерируем текст языковой моделью

Небольшая готовая модель продолжает начало фразы по одному токену. Сравниваем длину, выбор следующего токена и проверяем факты в выводе.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема](media/generation-loop.svg)

Нужны PyTorch, Transformers, NumPy и pandas. Веса скачиваются при первом запуске; на CPU генерация может быть медленной. Модель продолжения текста не обязана выполнять сложные инструкции.
