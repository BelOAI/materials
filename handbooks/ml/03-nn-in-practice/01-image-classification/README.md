# Распознаём изображения готовой моделью

Готовая ResNet-18 выдаёт классы всего кадра. Сравниваем три снимка одного предмета и записываем, когда ответ меняется.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема](media/classification-flow.svg)

Нужны Python, Pillow, PyTorch, TorchVision, Transformers и pandas. При первом запуске скачиваются веса. Ученик использует собственные разрешённые фотографии; результат зависит от состава классов ImageNet и условий съёмки.
