# Ищем изображения по описанию

Готовая модель CLIP ранжирует фотографии по тексту и сравнивает снимок с собственными описаниями. Мини-проект проверяет влияние формулировок и случаи без подходящего результата.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема](media/clip-search.svg)

Нужны PyTorch, TorchVision, Transformers, Pillow и pandas. При первом запуске скачиваются веса. Основной опыт использует английские описания; русский и белорусский проверяются отдельно.
