# Находим объекты на изображении

От класса всего снимка переходим к рамкам и маскам отдельных предметов. На одной фотографии сравниваем результаты при разных порогах.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема](media/detection-flow.svg)

Для практики нужны PyTorch, TorchVision, Pillow, Matplotlib и pandas; веса COCO скачиваются при первом запуске. На CPU модели могут выполняться медленно.
