## Первый запуск

Скачайте [библиотеки примеров](requirements.txt) и [архив изображений](images.zip). Установите библиотеки в отдельную среду Python 3.13: `python -m pip install -r requirements.txt`. Распакуйте архив рядом с выбранным ноутбуком — изображения окажутся в папке `data/`. [Происхождение файлов и подготовка Colab](data/SOURCES.txt) описаны отдельно.

Сначала выполните числовые упражнения без весов. Затем переключите `run_model` на `True` и запустите ноутбук сверху вниз. Полные опыты проверены на CPU; сохранённые [результаты и версии моделей](experiment-results.json) помогают сопоставить собственный запуск с разобранным примером. Веса загружаются отдельно и не включены в архив.
