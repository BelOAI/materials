# Ансамбли и случайный лес

Занятие 1.9 для школьников: усреднение и голосование, выбор строк с возвращением, бэггинг и случайный выбор признаков в каждой вершине дерева. Без разложения ошибки на смещение и дисперсию, доказательств и стекинга. Бустинг обозначен как тема следующего занятия.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Схема леса](media/forest.svg)

Нужны среднее арифметическое, понятия признака, регрессии, классификации и MAE, устройство дерева из занятия 1.4 и разделение обучения и проверки из занятия 1.8.

## Данные и запуск

Сквозной пример — прогноз времени 3D-печати по высоте, числу цветов и объёму пластика. Используется неизменённая [обучающая таблица из занятия 1.7](../07-features-regularization/data/train.csv): 300 синтетических заказов. Происхождение данных и механизм генерации описаны в [генераторе](../07-features-regularization/data/generate.py). Проверочные и итоговые ответы из предыдущих занятий не используются.

Ноутбук запускается сверху вниз из этой папки в копии репозитория со средой учебника. Для отдельного скачанного ноутбука необходимо также сохранить соседнюю папку `07-features-regularization/data/` с `train.csv`, сохранив относительный путь. Код сравнивает две заранее заданные модели на одинаковых трёх разбиениях; результаты служат учебному сравнению, а не независимой итоговой оценке после подбора. Ноутбук синхронизируется с текстом штатным `utils/scripts/handbook_notebooks.py`.

## Источники и адаптация

- [Хендбук Яндекса, «Ансамбли в машинном обучении»](https://education.yandex.ru/handbook/ml/article/ansambli-v-mashinnom-obuchenii): разделы о бэггинге и случайном лесе задают последовательность понятий. Вместо математических выводов — собственные примеры усреднения и выбора заказов с возвращением.
- [scikit-learn, Ensembles](https://scikit-learn.org/stable/modules/ensemble.html#forest): проверены причины разнообразия деревьев, ограничения усреднения и отличие голосования от усреднения вероятностей в библиотеке.
- [RandomForestRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html): проверены настройки. `max_features=2` задан явно: значение по умолчанию у регрессора разрешает все признаки. Описание выбора двух признаков — базовая модель алгоритма; библиотека может проверить дополнительные признаки, если среди выбранных не найдено ни одного допустимого разбиения.
- [RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html): проверено правило усреднения оценок вероятностей.

Все числовые мини-примеры, схема и вопросы подготовлены для этого занятия. Результаты таблицы воспроизводятся кодом; выводы о настоящих принтерах по синтетическим данным не делаются.
