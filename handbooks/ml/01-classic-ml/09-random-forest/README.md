# Ансамбли и случайный лес

Статья 1.9 для базового школьного учебника. Последовательное объяснение ансамблей, бэггинга и случайного леса с простыми числовыми примерами, без разложения ошибки на смещение и дисперсию и без математических доказательств.

[Статья](content.md) · [Пример на Python](notebook.ipynb) · [Иллюстрации](media/)

Числовые примеры сопровождаются схемами усреднения, бутстрапа и выбора признаков. Пример на Python, названия параметров и особенности реализации scikit-learn приведены в отдельном ноутбуке.

## Пример на Python

Ноутбук сравнивает дерево и лес на одинаковых трёх разбиениях 300 синтетических заказов из [таблицы статьи 1.7](../07-features-regularization/data/train.csv). Запускать сверху вниз из этой папки в копии репозитория со средой учебника. При отдельном скачивании сохранить также соседний файл `07-features-regularization/data/train.csv` с тем же относительным путём. Происхождение данных описано в [генераторе](../07-features-regularization/data/generate.py).

Правильное время и номер заказа не используются как признаки. Проверочные и итоговые ответы из предыдущих статей не используются. Результаты относятся к учебному набору, а не к настоящим принтерам.

## Источники и адаптация

Ссылки приведены в поле `references` файла [meta.yaml](meta.yaml); сайт показывает их в разделе «Дополнительные материалы».

Структура объяснения опирается на статью Яндекса об ансамблях: объединение предсказаний, бэггинг, случайный лес и его параметры. Математические выводы и стекинг опущены; числовые примеры и SVG-иллюстрации подготовлены для этого материала. Условные деревья и их пороги на схемах служат для объяснения алгоритма и не воспроизводят модель из ноутбука.

Особенности scikit-learn сверены с документацией: классификатор усредняет вероятности, а в регрессоре явно задано `max_features=2`. Библиотека может рассмотреть дополнительные признаки, если среди выбранных нет допустимого разбиения; в основном тексте используется базовое объяснение алгоритма.
