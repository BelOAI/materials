# Ансамбли и случайный лес

Статья 1.9 для базового школьного учебника. Последовательное объяснение ансамблей, бэггинга и случайного леса с простыми числовыми примерами, без разложения ошибки на смещение и дисперсию и без математических доказательств.

[Статья](content.md) · [Пример на Python](notebook.ipynb) · [Схема](media/forest.svg)

По редакционному указанию пользователя материал оформлен как объясняющая статья в стиле хендбука Яндекса. План занятия, блок целей, практические задания и итоговый опрос не включены. Полный пример на Python вынесен в отдельный ноутбук, а не дублирует текст статьи.

## Пример на Python

Ноутбук сравнивает дерево и лес на одинаковых трёх разбиениях 300 синтетических заказов из [таблицы статьи 1.7](../07-features-regularization/data/train.csv). Запускать сверху вниз из этой папки в копии репозитория со средой учебника. При отдельном скачивании сохранить также соседний файл `07-features-regularization/data/train.csv` с тем же относительным путём. Происхождение данных описано в [генераторе](../07-features-regularization/data/generate.py).

Правильное время и номер заказа не используются как признаки. Проверочные и итоговые ответы из предыдущих статей не используются. Результаты относятся к учебному набору, а не к настоящим принтерам.

## Источники

- [Яндекс, «Ансамбли в машинном обучении»](https://education.yandex.ru/handbook/ml/article/ansambli-v-mashinnom-obuchenii): ориентир для структуры и последовательности понятий. Математические выводы и стекинг опущены; примеры и схема подготовлены для этой статьи.
- [scikit-learn, Ensembles](https://scikit-learn.org/stable/modules/ensemble.html#forest): разнообразие деревьев и ограничения усреднения.
- [RandomForestRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html): настройки, в том числе явное `max_features=2`. Библиотека может рассмотреть дополнительные признаки, если среди выбранных нет допустимого разбиения; в основном тексте используется базовое объяснение алгоритма.
- [RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html): усреднение оценок вероятностей классов.
