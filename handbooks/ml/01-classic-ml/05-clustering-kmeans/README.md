# Кластеризация и K-means

Группировка восьми точек без готовых ответов: два ручных шага K-means, сравнение начальных центров и классический набор «Ирисы».

[Текст](content.md) · [Схема двух запусков](media/two-starts.svg) · [Диаграмма ирисов](media/iris-scatter.svg)

Для ручного примера нужны координаты точек, среднее арифметическое и возведение числа в квадрат. Для опыта с ирисами понадобится `scikit-learn`; данные входят в библиотеку.
