# Честная оценка качества

Выбор метрики и настройки модели на учебных данных, однократная итоговая проверка и поиск утечки между связанными объектами.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Итоговые заказы без ответов](data/final.csv) · [Ответы для самопроверки](data/final_answers.csv) · [Схема проверки](media/evaluation-flow.svg) · [Код эксперимента](evaluate.py)

Нужны основы решающих деревьев из [занятия 1.4](../04-decision-trees/README.md) и учебные данные [занятия 1.7](../07-features-regularization/README.md). Для запуска примеров потребуются `pandas` и `scikit-learn` из [окружения учебника](../../00-intro/01-environment/requirements.txt). Все заказы синтетические; [генератор](data/generate.py) фиксирует итоговый набор.
