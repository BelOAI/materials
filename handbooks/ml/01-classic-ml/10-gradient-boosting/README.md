# Градиентный бустинг и табличная задача целиком

Завершающий параграф первой главы: первый шаг бустинга вручную и сравнение моделей на синтетических заказах 3D-печати.

[Текст](content.md) · [Ноутбук](notebook.ipynb) · [Итоговые заказы](data/final.csv) · [Ответы](data/final_answers.csv) · [Схема](media/first-step.svg) · [Код проверки](evaluate.py)

Для запуска нужен [учебный набор из занятия 1.7](../07-features-regularization/data/train.csv). Запускайте ноутбук из папки этого параграфа, сохраняя соседние каталоги главы. Нужны `pandas` и `scikit-learn` из [среды учебника](../../00-intro/01-environment/requirements.txt). Все времена придуманы для обучения; новую итоговую сотню создаёт [генератор](data/generate.py).

## Источники и адаптация

Параграф опирается на [линейную модель](../03-linear-regression/content.md), [ансамбли и лес](../09-random-forest/content.md), [работу с признаками](../07-features-regularization/content.md) и [честную оценку](../08-honest-evaluation/content.md). Из документации scikit-learn взяты смысл последовательного добавления деревьев и параметры `GradientBoostingRegressor`; ссылки указаны в [метаданных](meta.yaml). Ручной пример, схема и синтетическая итоговая сотня подготовлены для этого занятия. Для ясности рассматривается регрессия с квадратичной ошибкой; другие функции потерь и реализации бустинга остаются за рамками параграфа.
