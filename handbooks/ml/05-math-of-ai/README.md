# Математика ИИ

Эта глава отвечает на вопросы о работе знакомых моделей: какую ошибку они уменьшают, как получают новые веса, что означают их векторы и оценки, сколько памяти им требуется. Это черновик для читателей 10–11 классов. Систематические основы линейной алгебры и анализа будут в отдельном математическом учебнике.
