# Шаблон параграфа

Скопируйте эту папку внутрь главы как `01-<slug>` и добавьте имя папки в `paragraphs` главы. Порядок задаётся списком, а не номером папки.

- `meta.yaml` — slug, название, описание, авторы, статус и список скачиваемых ресурсов.
- `content.md` — учебный текст без заголовка первого уровня.
- `media/` — изображения, ссылки из текста: `media/<имя>`.
- `data/` — данные, ссылки из текста: `data/<имя>`.

README описывает назначение и подготовку параграфа. Метаданные авторов не дублируйте здесь: они хранятся в YAML и отображаются на сайте.

Замените шаблонные метаданные, напишите собственный текст, укажите источники. Для готового текста установите `status: draft` и `build: true`. При добавлении первого параграфа переведите главу из `planned` в `draft`. Ноутбук, если он нужен, перечислите в `resources`; для синхронизации с текстом задайте `sync_notebook: true`.

Папки с префиксом `_` не включаются в каталог, публикацию и выполнение ноутбуков.
