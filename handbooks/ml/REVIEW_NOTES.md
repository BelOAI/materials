# Отложенные замечания к ML-хендбуку

Обновлено 28 октября 2026 года. Подробный разбор всех десяти параграфов, общий маршрут, оценки нагрузки и проекты задач для Яндекс Контеста находятся в [редакционном аудите первой главы](01-classic-ml/EDITORIAL_REVIEW.md). Целевая аудитория — школьники 10–11 классов, увлечённые математикой и программированием и начинающие изучать ИИ/МЛ. Отдельные хендбуки по Python и математике для Data Science помогут с входной подготовкой. Замечания не требуют убирать математическое углубление: его нужно сделать видимым как дополнительный уровень.

## Подтверждённые несогласованности

1. [Настройка среды](00-intro/01-environment/content.md) утверждает, что первое занятие не требует дополнительных библиотек и все данные находятся внутри ноутбука. [Практика 1.1](01-classic-ml/01-first-experiment/content.md) использует pandas и отдельные `train.csv`, `test.csv`, `test_answers.csv`. Нужно согласовать вводную инструкцию с текущим занятием.
2. Инструкция для Colab в том же введении предлагает загрузить данные рядом с ноутбуком, а ноутбук 1.1 читает их по путям `data/*.csv`. Нужно явно показать, как сохранить папку `data` при работе в Colab.

## Входная подготовка и маршруты

- Параграф 1.3 теперь существует. При редактуре согласовать его объяснение регуляризации с [параграфом 1.7](01-classic-ml/07-features-regularization/content.md): у линейной модели штрафуют коэффициенты, у дерева ограничивают построение. Проверить уровень обязательного и дополнительного материала.
- Перед 1.1 обозначить нужные навыки работы с CSV и pandas; до появления отдельного хендбука по Python дать краткий маршрут к этим навыкам. Само занятие с большим набором данных сохранять.
- Для 1.2 явно указать опору на координаты, модуль, теорему Пифагора и дроби; для 1.4 — на квадратичную ошибку и, для разбора оптимального пня, алгебру и сложность алгоритмов. Глубину этих разборов сохранять для мотивированной аудитории.
- Для 1.5 и последующих практик обозначить, где нужны более уверенный Python, массивы, pandas и API scikit-learn. По мере появления хендбуков по Python и математике добавить адресные ссылки на соответствующие разделы.
