# Свёртки и устройство CNN

Параграф 2.3 программы для учеников 8–9 классов. На небольшом изображении разбираются фильтр, карта признаков, дополнение нулями и шаг. Затем объясняется, как расширяется область видимости последовательных свёрток.

- `content.md` — основной текст и десять вопросов самопроверки.
- `media/` — восемь цветных SVG-иллюстраций с доступными описаниями. Рисунок 8 основан на схеме Яндекса с увеличенными векторными подписями и сохраняет светлый фон оригинала; остальные рисунки поддерживают обе темы.
- `generate_figures.py` — автономный исходник рисунков 1–7 на стандартной библиотеке Python; запуск из любой папки создаёт `media/` рядом со скриптом.
- `notebook.ipynb` — самостоятельное дополнение на NumPy: расчёт карт, проверка сдвига и направлений границы, дополнение и шаг, область видимости и задача по программированию. Выполняется сверху вниз без загрузки данных.

Источники и характер адаптации указаны в `meta.yaml`. Текст, числовые примеры и схемы, кроме рисунка 8, подготовлены заново; код и изображения из материалов Berkeley не копировались. Для двух фильтров используется одна и та же граница, поэтому все отклики можно проверить вручную.

Служебные PDF для согласования и файлы локальной вёрстки в публикацию не включены.
