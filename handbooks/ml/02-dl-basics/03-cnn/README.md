# Свёртки и устройство CNN

Параграф 2.3 программы для учеников 8–9 классов. На небольшом изображении разбираются фильтр, карта признаков, ReLU, пулинг, дополнение нулями и шаг. Затем прослеживаются размеры данных в сети для распознавания цифр.

- `content.md` — основной текст и десять вопросов самопроверки.
- `media/` — одиннадцать цветных SVG-иллюстраций с доступными описаниями и поддержкой тем.
- `notebook.ipynb` — самостоятельное дополнение на NumPy: расчёт карт, проверка сдвига и направлений границы, ReLU, пулинг и задача по программированию. Выполняется сверху вниз без загрузки данных.

Источники и характер адаптации указаны в `meta.yaml`. Текст, числовые примеры и схемы подготовлены заново; код и изображения из материалов Berkeley не копировались. Для двух фильтров используется одна и та же граница, поэтому все отклики можно проверить вручную.

Служебные PDF для согласования и файлы локальной вёрстки в публикацию не включены.
