# От линейной модели к нейросети

Нейрон, скрытый слой и прямой проход сети на примере задачи XOR.

[Текст](content.md) · [Точки XOR](media/xor-points.svg) · [Схема сети](media/network.svg)

В параграфе нужны линейная модель и логистическая регрессия из главы 1, а также представление о векторах, матрицах и формах данных. Для примеров достаточно Python 3.14 без внешних библиотек: код в тексте выполняет прямой проход вручную.

Проверить примеры можно командами из текста. Схема показывает сеть 2–2–1, но конкретные веса задаются отдельно в разделе «Разбираем сеть для XOR».
