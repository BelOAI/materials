## Чему научимся

Читать сообщения об ошибках и проверять обычные, граничные и недопустимые входы.

## Ошибки и трассировка

`SyntaxError` означает, что запись программы не удалось разобрать. Во время выполнения возможны `NameError` (неизвестное имя), `TypeError` (неподходящий тип), `ValueError` (недопустимое значение), `IndexError` и `KeyError`.

Трассировка — список вызовов функций, приведших к ошибке, с указанием файлов и строк. В ней сначала прочитайте последнюю строку: тип и сообщение. Затем найдите последнюю строку своего кода и проследите вызовы выше. Например, `int("крыло")` приводит к `ValueError`: строку нельзя прочитать как целое число.

`try` выполняет код, `except ValueError` обрабатывает только исключение типа `ValueError`. Не перехватывайте все ошибки, чтобы просто продолжить работу: потерянные строки данных изменят результат незаметно. Там, где неверный вход нельзя исправить, явно сообщите о нём через `raise`.

```python
try:
    number = int("крыло")
except ValueError:
    print("Не удалось прочитать целое число")
```

Если строка `total = value` написана вместо `total += value`, программа может работать без исключения, но давать неверный ответ. Это логическая ошибка. Для её поиска нужен пример с известным ответом, а не только отсутствие красного сообщения. Например, для `[3, 5]` сумма должна быть 8, а ошибочный цикл оставит 5.

## Разобранный пример: среднее с проверкой

`assert` проверяет утверждение и вызывает `AssertionError`, если оно ложно. `pass` означает «ничего не делать», а `else` после `try` выполняется, если исключения не было. Для проверки ошибок важно убедиться, что исключение действительно возникло. `assert` подходит для учебных тестов, но проверку пользовательских данных делайте через `if` и `raise`: при оптимизированном запуске Python утверждения могут отключаться.

```python
def average(values):
    if len(values) == 0:
        raise ValueError("Среднее пустого набора не определено")
    return sum(values) / len(values)

assert average([10, 14, 18]) == 14
assert average([7]) == 7
try:
    average([])
except ValueError:
    pass
else:
    raise AssertionError("Пустой вход должен вызвать ValueError")
```

Встроенные `min(values)` и `max(values)` находят наименьшее и наибольшее значения непустого набора. У пустого набора минимума и максимума нет. Проверку пустоты списка можно записать `if len(values) == 0` или короче `if not values`: пустой список считается ложным.

Разделите чтение данных, проверку и вычисление на разные функции. Тогда ошибку можно искать на маленьком примере, не запуская весь эксперимент.

## Проверка не только обычного случая

Небольшой тест должен проверять смысл функции. Для размаха значений нужны обычный набор, один элемент, одинаковые числа и пустой набор. Встроенные `min` и `max` находят крайние значения непустого списка.

```python
def spread(values):
    if len(values) == 0:
        raise ValueError("Нужны измерения")
    return max(values) - min(values)

assert spread([3, 9, 4]) == 6
assert spread([5]) == 0
assert spread([2, 2]) == 0
```

При неверном ответе уменьшите пример до минимального, на котором ошибка сохраняется. Следите за ожидаемым результатом: тест, который просто копирует ошибочную формулу программы, не обнаружит проблему.

### 2. Базовая

Достаточно ли поймать ошибку пустого входа, чтобы проверить его обработку?

<details>
<summary>Подсказка</summary>

Что если ошибка вообще не возникла?

</details>

<details>
<summary>Решение</summary>

Нет. Тест должен отдельно заметить отсутствие ожидаемого исключения.

</details>

### 3. Прикладная

Проверьте spread на отрицательных числах `[-5, -2]`.

<details>
<summary>Подсказка</summary>

Размах — максимум минус минимум.

</details>

<details>
<summary>Решение</summary>

```python
assert spread([-5, -2]) == 3
```

</details>

### 4. Прикладная

Напишите тест ошибки `spread([])`.

<details>
<summary>Подсказка</summary>

Используйте else после try.

</details>

<details>
<summary>Решение</summary>

```python
try:
    spread([])
except ValueError:
    pass
else:
    raise AssertionError("Пустой вход не отклонён")
```

</details>

### 5. Олимпиадная

Почему замена неверной массы нулём меняет среднее?

<details>
<summary>Подсказка</summary>

Отсутствующее измерение превращается в настоящее число.

</details>

<details>
<summary>Решение</summary>

Ноль участвует и в сумме, и в количестве. Нужно явно сообщить об ошибке или учитывать пропуск по осмысленному правилу.

</details>

### 6. Олимпиадная

Все тесты на положительных числах прошли. Доказывает ли это работу поиска максимума на любых числах?

<details>
<summary>Подсказка</summary>

Проверьте алгоритм, начинающий максимум с нуля.

</details>

<details>
<summary>Решение</summary>

Нет. На отрицательном наборе такой алгоритм вернёт несуществующий ноль. Нужны разные классы входов.

</details>
