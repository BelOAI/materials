# Учебники BelOAI

Учебники BelOAI предназначены для школьников, которые хотят разобраться в искусственном интеллекте и подготовиться к олимпиаде. Они дополняют занятия курса: здесь можно подробнее изучить теорию, разобрать примеры и выполнить задания. Материалы подходят для самостоятельной работы и для занятий с преподавателем.

## Машинное обучение

Сейчас в разделе представлен [учебник по машинному обучению](ml/README.md). Он объясняет, как строить модели, которые находят закономерности в данных, делают прогнозы и распознают объекты. Изучение начинается с простых экспериментов с данными. В программу также входят классические методы машинного обучения, нейронные сети и математические основы их работы.

Теория сопровождается примерами на Python, практическими заданиями и вопросами для самопроверки. К отдельным параграфам приложены данные и тетради Jupyter, в которых можно запускать и изменять код. Преподаватели могут использовать эти материалы при подготовке уроков и подбирать задания с учётом знаний учеников.

## С чего начать

Откройте учебник и выберите нужную тему в оглавлении. Если вы только приступаете к занятиям, начните с [настройки среды для работы с Python](ml/00-intro/01-environment/content.md), а затем выполните [первый эксперимент с данными](ml/01-classic-ml/01-first-experiment/content.md).

При чтении пробуйте запускать примеры, менять их и объяснять полученные результаты. Выполняйте задания и отвечайте на вопросы самостоятельно; подсказки и ответы помогут проверить себя.

Учебник ещё готовится. Опубликованные параграфы доступны в оглавлении, а темы, для которых текст пока не написан, отмечены отдельно. Новые материалы будут появляться по мере готовности.
