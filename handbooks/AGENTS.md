# Работа с учебниками

Читайте только правила, относящиеся к текущей задаче:

- Текст, описания глав и задания: [язык и структура изложения](guidelines/content.md).
- Рисунки и таблицы: [оформление](guidelines/visuals.md).
- Структура, метаданные и публикация: [руководство по сборке](../utils/scripts/README.md#учебник-по-машинному-обучению).
- Печатная версия: [профиль PDF](../utils/pdf/README.md).

Для подготовки и редактуры учебного текста используйте [handbook-writing](../.agents/skills/handbook-writing/SKILL.md), для создания и проверки графики — [handbook-visuals](../.agents/skills/handbook-visuals/SKILL.md). Скиллы описывают порядок работы, руководства — общие правила для авторов и агентов.

Ограничивайте изменения порученной задачей: правка графики не разрешает переписывать основной текст, программу или код сборки. Исключения оформления и выбор проверок по масштабу изменения описаны в руководстве по графике; не загружайте остальные руководства без необходимости.
