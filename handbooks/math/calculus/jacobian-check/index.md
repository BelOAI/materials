## Чему научимся

Согласовывать формы правила цепочки и проверять компоненты градиента конечными разностями.

## Якобиан и правило цепочки

Если функция $g$ возвращает несколько чисел, её производные удобно собрать в матрицу Якоби $J$. Строка соответствует выходу, столбец — входу: $J_{ij}=\partial g_i/\partial w_j$.

Для $g(w_1,w_2)=(w_1+w_2,\,w_1-w_2)$:

$$J=\begin{pmatrix}1&1\\1&-1\end{pmatrix}.$$

Скалярная функция возвращает одно число. Если такая функция $f$ принимает результат $g$, то градиент композиции равен $\nabla_w f(g(w))=J^T\nabla_g f$. Формы: $g$ имеет $m$ выходов, $w$ — $d$ входов, $J$ — $m\times d$, результат — столбец длины $d$. Нижний индекс у $\nabla_w$ указывает, по каким переменным берутся производные; у $\nabla_g f$ — по компонентам промежуточного результата $g$. После транспонирования размеры матриц позволяют выполнить это умножение.

## Разобранный пример: два способа вычислить градиент

Проверим правило на $f(g_1,g_2)=g_1^2+g_2^2$. При $w=(1,2)$ получаем $g=(3,-1)$, $\nabla_g f=(6,-2)^T$, затем $J^T(6,-2)^T=(4,8)^T$. Прямая подстановка даёт $f(g(w))=(w_1+w_2)^2+(w_1-w_2)^2=2w_1^2+2w_2^2$ с тем же градиентом $(4,8)^T$.

В численной проверке используем ошибку $L(w)=(2w_1+w_2-5)^2$ из предыдущего урока.

## Численная проверка

Сначала можно выполнить проверку вручную. Код ниже — дополнительная иллюстрация для знакомых с [функциями Python](../../../python/functions-files/functions-arguments/) и [списками](../../../python/collections-memory/lists-tuples/); для решения математических задач запускать его не требуется.

При малом $h>0$ частную производную можно приблизить центральной разностью: изменить только выбранный параметр на $+h$ и $-h$, вычесть значения функции и разделить на $2h$.

Например, для первого веса в точке $(1,1)$ и $h=0.001$ получаем $L(1.001,1)=3.992004$ и $L(0.999,1)=4.008004$. Их разность, делённая на $0.002$, равна $-8$ — первой компоненте градиента. Второй вес при этой проверке остаётся равным 1.

В коде `1e-5` означает $10^{-5}$, а `round(value, 5)` округляет число для вывода до пяти знаков после точки. Копии `plus` и `minus` нужны, чтобы отдельно менять одну координату, сохраняя исходную точку.

```python
def loss(w):
    prediction = 2 * w[0] + w[1]
    return (prediction - 5) ** 2

w = [1.0, 1.0]
h = 1e-5
numeric = []
for j in range(len(w)):
    plus = w.copy()
    minus = w.copy()
    plus[j] += h
    minus[j] -= h
    numeric.append((loss(plus) - loss(minus)) / (2 * h))
print([round(value, 5) for value in numeric])  # [-8.0, -4.0]
```

Слишком большой шаг ухудшает приближение, слишком маленький усиливает ошибки округления при вычитании близких чисел. Сравнивайте с допуском, а не через точное равенство. Проверка на одной точке не доказывает формулу, но помогает найти пропущенный знак, множитель или неверную ось. Проверяйте несколько разных точек; у излома центральная разность не гарантирует существования производной.

## Разобранный пример: прямоугольный Якобиан

Пусть g(a,b)=(a,b,a+b): два входа, три выхода. Строки J равны (1,0),(0,1),(1,1), форма 3×2. Если f(g)=g₁+2g₂+3g₃, градиент по g равен (1,2,3). Произведение Jᵀ на этот столбец даёт (4,5). Прямая подстановка f=4a+5b подтверждает ответ.

Квадратный пример способен скрыть ошибку транспонирования, потому что размеры совпадают. Прямоугольный пример её обнаруживает до вычислений: J без транспонирования не умножается на столбец длины 3. Для численной проверки также меняют одну входную координату, сохраняя остальные.

## Типичные ошибки

Строки Якобиана относятся к выходам, столбцы к входам. Не меняйте все координаты одновременно при проверке одной компоненты и не делайте шаг бесконечно малым в приближённых вычислениях.

## Задачи

### 1. Базовая

Какова форма Якобиана функции с тремя входами и двумя выходами?

<details>
<summary>Подсказка</summary>

Строки — выходы.

</details>

<details>
<summary>Решение</summary>

2×3: по строке на каждый из двух выходов и по столбцу на каждый из трёх входов.

</details>

### 2. Базовая

Какой параметр меняют при проверке одной компоненты градиента?

<details>
<summary>Подсказка</summary>

Остальные фиксированы.

</details>

<details>
<summary>Решение</summary>

Только выбранную координату на +h и −h, остальные оставляют как в исходной точке.

</details>

### 3. Прикладная

Для g(a,b)=(a+b,a−b) выпишите Якобиан.

<details>
<summary>Подсказка</summary>

По одной производной каждого выхода по каждому входу.

</details>

<details>
<summary>Решение</summary>

Для первого выхода производные по a,b равны 1,1; для второго 1,−1. Это и есть две строки Якобиана.

</details>

### 4. Прикладная

Для L(w)=(3w−6)² найдите производную при w=1.

<details>
<summary>Подсказка</summary>

Правило цепочки.

</details>

<details>
<summary>Решение</summary>

6(3w−6), при 1 — −18.

</details>

### 5. Олимпиадная
Для $L(a,b)=a^2+ab$ в точке (2,3) ученик меняет обе координаты одновременно и считает $[L(2+h,3+h)-L(2-h,3-h)]/(2h)$ при $h\ne0$. Что получается и почему это не проверка каждой компоненты градиента?

<details>
<summary>Подсказка</summary>

Раскройте оба квадрата и произведения. Сравните результат с двумя отдельными частными производными.

</details>

<details>
<summary>Решение</summary>

$L(2+h,3+h)=10+9h+2h^2$, а $L(2-h,3-h)=10-9h+2h^2$. Частное равно $18h/(2h)=9$ при любом ненулевом h. Градиент в (2,3) равен (7,2), и 9 — сумма его компонент, а не каждая из них. Для проверки первой компоненты надо менять только a, для второй — только b. Нормирующий знаменатель 2h существенен: одна разность значений функции сама по себе стремилась бы к нулю.

</details>

### 6. Олимпиадная

Почему нельзя делать шаг центральной разности сколь угодно маленьким?

<details>
<summary>Подсказка</summary>

Вычитаются близкие приближённые числа.

</details>

<details>
<summary>Решение</summary>

Ошибки округления могут стать значительными относительно разности. Нужно сравнить несколько разумных шагов и использовать допуск.

</details>

## Итоги

Якобиан хранит производные выходов по входам. В обратном правиле цепочки работает его транспонированная матрица; конечные разности дают независимую численную проверку компонентов, если учтены шаг и погрешность.
