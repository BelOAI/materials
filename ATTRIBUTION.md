# Как указать авторство

При использовании учебных материалов по [CC BY 4.0](LICENSE-CC-BY-4.0) используйте общее обозначение «Авторы BelOAI», укажите источник и лицензию.

Персональные сведения об участниках проекта находятся в [CONTRIBUTORS.md](CONTRIBUTORS.md). В общих текстах репозитория и сайта используйте коллективное обозначение авторства. Подписи внутри учебных материалов сохраняются отдельно.

## Материал без изменений

> Материалы BelOAI. © Авторы BelOAI. Источник: https://beloai.github.io/materials/. Лицензия: CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/.

Для конкретного занятия добавьте название и дату из его `meta.yaml`.

## Материал с изменениями

> На основе материалов BelOAI: https://github.com/BelOAI/materials. © Авторы BelOAI, CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/. Изменения: [кратко опишите изменения].

## Программный код

Для темы LaTeX и скриптов сохраняйте полный текст [MIT](LICENSE-MIT), включая исходное уведомление:

> Copyright (c) 2026 BelOAI Authors

Распределение лицензий по путям: [LICENSING.md](LICENSING.md).
